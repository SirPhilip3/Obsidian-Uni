detecting corner :

corner definition : 
+ gradient at the corner not defined 
+ in larger region centered at the corner -> gradient will show 2 strong different direction -> if they have similar balance (similar amount of pixels for the 2 directions)

harris corner detector

second moment matrix -> for every pixel contains info about the shape around 

no changes = no corner

suppose we are looking at a point $x_0$ 

we can approximate the value of image when $x_0 + h$-> we do *tailor expansion* , assuming that locally funciton is linear 

$$
I(x_{0}+h) \approx I(x_{0}) + \nabla I(x_{0})^T h
$$
h vector

intensity at h_0 + gradient of image multipled (dot product) by h
$$
I(x_{0}+h) - I(x_{0}) \approx \nabla I(x_{0})^T h
$$
smaller h the better 

we are not intrested in the sign -> just how much intensity changes 

$$
(I(x_{0}+h) - I(x_{0}))^2 \approx h^T \nabla I(x_{0}) \nabla I(x_{0})^T h
$$
square form of scalar prod 

instead of looking at specific point -> look at neighbouring pixels 

-> weighted average -> less importance to the ones further away 
$$
\sum_{x \in \Omega_{x_{0}}} w(x-x_{0})(I(x_{0}+h) - I(x_{0}))^2
$$
weights $w$ can be gaussian windowin function, constant etcc

$$
\sum_{x \in \Omega_{x_{0}}} w(x-x_{0}) h^T \nabla I(x_{0}) \nabla I(x_{0})^T h
$$
$h$ can be outside the summation
call this $E(x_{0})$

slides

$I_u$ vetical derivative , $I_v$ horizontal derivative 

second moment matrix :
$$
C = \begin{bmatrix}
\sum I_{u}^2 & \sum I_{u}I_{v} \\
\sum I_{v}I_{u} & \sum I_{v}^2 \\
\end{bmatrix}
$$

it's positive semi-definite -> both eigenvalues >= 0 

determinat of matrix -> prod of 2 eigenvalues 
trace -> sum of 2 eigenvalues -> sum of diagonal elemetns -> squares so must be >= 0

one of the 2 is 0 -> det is always 0 show with formula  -> one eigenvalue must be 0 since trance diff 0 

sum of pos-semidef matrix -> pos-semidef matrix 

90 deg well def corner -> we get a diagonal matrix for $C$ since the sum of vertica mult horizontal will alwyas be 0 -> the gradeint will always have only vertical or only horizontal component 

flat region -> 0 matrix -> botheigenvalues close to 0 -> flat region

in an edge -> one eigenvalue = 0 we can find edges

if both eigenvalues are >>0 then we are in a corner 

in non perfect aligned case -> we need to rotate the whole image so that it becomes actually aligned -> singular value decomposition 
$$
C = R \begin{bmatrix}
\lambda_{1} & 0 \\
0 & \lambda_{2}
\end{bmatrix} R^T
$$
$R$ -> rotation matrix 

harris corner detection -> not simple to get eigenvalues with SVD on full image 

response -> single number that says how much a point is a corner without decompositing the matrix -> det - k trace^2  

k is tunable param (0.04)

easier to compute then getting the actual eigenvalue 

2 similar eigenvalue -> $\lambda^2 - k(2\lambda)^2 = \lambda^2(1-4k)$ -> response scale with k -> with small value of k -> response will give large number 

if they are different -> one is large the other small -> product will be small , sum instead will be big -> second term will dominate -> respose will be negative (corner)
