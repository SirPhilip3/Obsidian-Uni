*morfological image processing* 

manipulate image based on a particular shape 

classical -> on binary images 

rapresent image just by set of white or black pixels coords

operations : 
+ set translation -> move all the points based on a vector Z = (z_1, z_2)
$(B)_{Z}$ produces a new set : $=\{c | c = b+z \quad \forall b \in B\}$ 

+ set reflection $\hat{B}$ -> negates the coords $\hat{B}=\{w | w = -b \quad \forall b \in B\}$ 
rotates 180 deg 

structuring element -> sets of coords -> used to probe the image for properties of intrest 
set of coords -> example ((0,0)(1,0)(0,1)(-1,0)(0,-1)) 3x3 kernel center (0,0) origin

like convolution without weights -> we care only about the shape 

*erosion*
erosion of set A(bin image) by set B (structuring element)
$A \ominus B = \{ z | (B)_{Z} \cap \bar{A}= \emptyset \}$ all the point such that B translated by Z and intersected with compliment of A (black pixel) is the empty set -> that translation is part of the new set 

we dont care abount boundaries -> always inside the image

erosion remove all the things that are smaller than the structuring element and shrinks all the remaning things 

*dialation*

$A \oplus B = \{ z | (\hat{B})_{Z} \cap A \neq \emptyset \}$  reflect structuring element + translation -> intersected with A it's not empty than keep that point -> at least 1 point that overlaps with A keep that point -> opposite as erosion 

set reflection same reason as convolution -> otherwise the element will be reflect in the output 

combining them : 
*opening* $A o B = (A \ominus B) \oplus B$
*closing* $A \bullet B = (A \oplus B) \ominus B$

order matters
*opening* 2 things cancels out -> but if something disappears wont be bring back on dialation 
*closing* -> the first dialation closes "gap" between 2 object dialation will make it smaller but not break the gap

both remove the noise and remove gaps -> first open then close $(A o B) \bullet B$

morphology works on set of white pixel -> we can just use the opposite operation or invert image

*dialtion*

same but take *maximum* value

$[f \oplus b] = \max_{(s,t)\in b}\{f(x-s,y-t)\}$ -> flipped around origin

keeps bright fetures + expanded , supress small dark features 

*opening* and *closing* same as before

closing -> remove dark things smaller than se , keep bright ones similar
