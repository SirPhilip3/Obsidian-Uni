approximation for evaluating point curve distance 

+ algebraic distance 

the evaluation of the implicit form for the curve at point px py (0 if on the curve) , the further away the point the worse the approximation , normalization of the coefficent because any mult of px py will give the same solution , normalization with some constraint like can lead to evaluating the exact point line distance (for line normalize with $a^2+b^2=1$ will give perfect distance)

most of the time norm of set of all param = 1 -> we can reduce the problem to eigenvalue problem 

if we force only some params to some values -> we can remove possible solutions 

+ normalized distance

better approx -> evaluate the curve normalized by the norm of the gradient of the curve at that point -> we need to compute the gradient
$$
\frac{\phi}{||\nabla \phi||}
$$
