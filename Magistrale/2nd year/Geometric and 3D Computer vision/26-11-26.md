ransac 

1. select random subset (minima) of data points -> hypotetical inliers (2 point to extract line)
2. fit the model on they hypotetical inliers (with 2 point just get the line)
3. test all the other point to mark them as inliers and outliers (ex for line -> allow some threshold for which around the line you consider them as inliers ) -> inliers -> consensus set 
4. repeat for N iterations -> return the model that produced the largest consensus set

works good if we have lot's of inliers in respect to outliers 
if we need few points to define the model in respect to the total number of points 

prosac -> tries every subset of point 

iteration needed 

prob to find good model given the samples :
$$p = 1-(1-(1-e)^s)^N$$
e -> prob point is outlier (from the data?)
s -> needed points to define the model
N -> ransac iterations 

(1-e)^s -> prob to get s inlier in a row (defining the model)
1 - (1-e)^s -> at least 1 point is wrong 
(1 - (1-e)^s)^N -> prob of being unlucky for all iteration
1- that -> at least 1 success

$$N = \frac{\log (1-p)}{\log(1-(1-e)^s)}$$
